# 안녕하세요, AI 엔지니어를 준비하는 개발자입니다.

다년간 금융·기업 고객의 콜센터 녹취 시스템을 개발·운영하며 서비스 흐름을 분석하고 문제의 원인을 추적해 해결했습니다. 현재 Python과 통계·데이터 분석을 학습하며 AI 엔지니어로 전환하고 있습니다. 데이터의 패턴과 알고리즘의 원리를 깊이 이해하고, 실제 문제를 해결하는 모델을 직접 개발하는 엔지니어를 목표로 합니다. 기존 개발 경험을 바탕으로 안정적인 구현과 지속적인 개선에 기여하겠습니다.
